About Hanglet

Hanglet is a calm word game for a few minutes a day.

The idea is simple and old: guess a word one letter at a time before a drawing is finished. Hanglet adds a Daily challenge that is the same for everyone, a level path, a race against the clock and small rewards that make it nice to come back.

Made to be light

Hanglet is built with plain HTML, CSS and JavaScript. No frameworks, no trackers, no ads and no account. It loads fast, works offline once you have visited it, and you can install it on your phone like an app.

The words

There are 480 English words in eight categories: animals, food, countries, sports, nature, jobs, science and music. Every word was picked to be friendly for all ages.

Where it comes from

Hanglet started as a small Python terminal game made while following the Codédex Python tutorial, and was rebuilt from the ground up as a full web game.
